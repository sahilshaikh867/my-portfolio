Overview

What is an Evil Twin attack?

An Evil Twin attack is a Wi‑Fi attack where an attacker sets up a fake access point that looks like a legitimate network (same SSID), tricks users into connecting to it, and then intercepts their traffic or login credentials.

In this project, a safe lab was created using virtual machines and a dedicated Wi‑Fi adapter to learn how the attack works in practice and what misconfigurations make networks more vulnerable. The goal was educational, not to attack real users or networks.

Lab Setup & Flow

How the attack was simulated safely

High‑level lab design:

The lab used one Kali Linux machine (attacker), one legitimate access point (or simulated AP) and one victim device. The attacker cloned the SSID, started a fake AP with a higher signal, created a phishing‑style login page, and captured credentials when the victim tried to log in.

Step‑by‑step lab workflow
1. Environment setup Configured Kali Linux with a compatible Wi‑Fi adapter in monitor mode. Set up a separate network / test router to avoid impacting any real users.
2. Reconnaissance Used tools like airodump‑ng to scan for nearby SSIDs, identified the legitimate target network (e.g., “Campus‑WiFi”) and noted its channel and security settings.
3. Creating the Evil Twin Configured a fake access point using hostapd/airbase‑ng with the same SSID and stronger signal, plus a DHCP/DNS setup to redirect traffic to the attacker machine.
4. Captive portal page Deployed a simple phishing page that looked like a Wi‑Fi login/portal page to capture credentials when the victim tried to “log in” for internet access.
5. Victim connection The victim device was disconnected from the real AP (in the lab) and reconnected to the fake one, then asked to log in on the fake captive portal.
6. Capture & analysis Credentials entered on the phishing page were captured in Kali’s logs, then the student analyzed what went wrong from the defender’s perspective and how to prevent it.

Defense & Learnings

What this lab taught about security

Key security learnings
  • How attackers clone SSIDs and trick users using signal strength and familiar names.
  • Why HTTPS and certificate checking matter when entering credentials on web pages.
  • How network segmentation and proper Wi‑Fi configurations reduce the impact of such attacks.
  • The importance of user education: “Do not log in on random pop‑up Wi‑Fi portals”.
How to defend against Evil Twin
  • Use WPA2‑Enterprise / WPA3 and avoid completely open guest Wi‑Fi for sensitive tasks.
  • Encourage VPN usage on untrusted networks.
  • Monitor for rogue access points with wireless intrusion detection where possible.
